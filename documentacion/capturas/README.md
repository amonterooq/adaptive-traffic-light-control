# Procedencia de las capturas

Las imágenes PNG de esta carpeta se conservan desde la entrega académica.
Las vistas de circulación, Lusitania y la rotonda muestran la aplicación y
posiciones de agentes de SUMO. Las tablas muestran resultados sintéticos del
proyecto. La cartografía corresponde a OpenStreetMap, con la atribución visible.

La portada y la galería del README utilizan vistas de simulación y resultados.
No se han generado interfaces ficticias ni reconstruido movimientos para una demo.

Las capturas de informes de incidencias (`informe_incidencia.png` e
`informe_movil.png`) proceden de pruebas de interfaz que inyectan respuestas
de fallo para comprobar su presentación. No documentan una colisión observada
en un ensayo real ni se utilizan como evidencia de resultados experimentales.

Las pruebas repetidas durante la preparación produjeron capturas nuevas en una
carpeta temporal excluida. Sus comprobaciones se recogen en
[pruebas-navegador.json](../../docs/pruebas-navegador.json).
